 # Firma Bakalari poskytuje verejne seznam skol, adres jejich bakalaru.
Na strankach https://sluzby.bakalari.cz/api/v1/municipality a nasledne
https://sluzby.bakalari.cz/api/v1/municipality/a  
*na konci odkazu lze uvadet i vice znaku, podle nich se vypisi konkretni skoly*

Jednoduchym skriptem lze ziskat seznam skol, adres jejich bakalaru.

### Proc je to bezpecnostni riziko ? ###
Pripadni utocnici maji k dispozici seznam

Podnet jsem zadaval Bakalarum jako #239920 28. 7. 2023. Po kratke diskuzi jsem dostal posledni odpoved 27. 9. 2023, ktera
obsahovala cituji  
"ještě jednou jsme interně probrali Vaší připomínku k zabezpečení seznamu škol a shodli se, že máte pravdu. Endpoint s URL adresami škol zabezpečíme."
